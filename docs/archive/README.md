# 归档文档

本目录保存历史计划、已完成阶段设计、分支记录和早期路线图。

归档文档的用途是追溯背景，不再作为当前代码事实源。

当前实现事实请优先阅读：

- [当前实现概览](../CURRENT_IMPLEMENTATION.md)
- [架构说明](../ARCHITECTURE.md)
- [项目基线](../PROJECT_BASELINE.md)
- [维护基线](../MAINTAINER_BASELINE.md)
- [协议参考](../protocol-reference/README.md)

## 目录

- [`completed-plans/`](./completed-plans/)：已经落地或已被当前基线吸收的阶段计划。
- [`design-notes/`](./design-notes/)：早期设计、路线图、演进设想和未必完整落地的方案。
- [`branch-notes/`](./branch-notes/)：特定分支或历史阶段的状态记录。

## 阅读原则

- 如果归档文档和当前事实文档冲突，以当前事实文档为准。
- 如果需要恢复某个设计，请先核对当前代码和测试。
- 不要把归档文档中的 “Phase / proposed / roadmap” 直接当成当前实现承诺。
